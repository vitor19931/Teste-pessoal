# Portfólio Fotográfico - Estilo 46Graus

Este é um site de portfólio fotográfico inspirado na plataforma 46Graus, com seções para portfólio, galeria de downloads, loja online e contato. Inclui medidas de proteção contra capturas de tela.

## Funcionalidades

- **Página Inicial**: Hero section com chamada para ação.
- **Portfólio**: Grid de imagens com overlays descritivos.
- **Galeria de Downloads**: Seleção de fotos com proteção contra print screen.
- **Loja Online**: Seção com produtos (simulada).
- **Contato**: Formulário de contato.
- **Navegação**: Menu fixo com scroll suave.
- **Proteção contra Print Screen**:
  - Desabilita clique direito.
  - Impede seleção de texto.
  - Detecta tentativas de print screen e mostra aviso.
  - Overlay sutil nas imagens para dificultar capturas.

## Como Usar

1. Abra `index.html` em um navegador web.
2. Navegue pelas seções usando o menu.
3. Na galeria, selecione fotos e baixe-as.
4. Explore a loja e contato.

## Personalização

- Substitua as URLs das imagens por suas próprias fotos.
- Ajuste cores e estilos em `style.css`.
- Modifique comportamentos em `script.js`.
- Adicione mais seções ou páginas conforme necessário.

## Estrutura dos Arquivos

- `index.html`: Página principal com todas as seções.
- `style.css`: Estilos CSS para layout responsivo.
- `script.js`: JavaScript para interatividade e proteções.
- `README.md`: Esta documentação.

## Tecnologias

- HTML5
- CSS3 (com Google Fonts)
- JavaScript (Vanilla)

## Limitações

- A proteção contra print screen não é 100% eficaz.
- Loja e contato são simulados (para funcionalidade real, integre com backend).
- Site estático; para dinâmico, considere frameworks como React ou backend como Node.js.

Para mais recursos como os do 46Graus (blog, integrações), seria necessário um backend e banco de dados.
